The Founding Document

How the Round Table began, who started it, and how to challenge the founding rules.

The short version

On 17 October 2026, the maintainer seeded 7 proposals into a fresh database. Those 7 proposals are the founding rules. All 7 are in phase draft with author_entity_id = 'system'.

Why seed at all?

A voting system needs rules before it can vote. Rules need proposals. Proposals need a mechanism that doesn't exist until the rules exist. Bootstrap problem.

The cleanest way to break the loop: seed the minimum viable ruleset, then hand control to the community. Every seeded proposal is a real proposal — votable, challengeable, rejectable. None are locked or special.

The 7 founding proposals

rt0000 Ratify the Round Table Constitution

rt0001 Define Entity

rt0002 Set Default Thresholds

rt0003 Establish the Objector's Bench

rt0004 Define the Execution Bridge

rt0005 The Reconsider Window

rt0006 First Feature Proposal (open)

How to challenge them

  1. Log in with an eligible account (7+ days old, prior activity).
  2. Open any founding proposal on the Round Table page.
  3. Vote NO — public, on the record, permanent.
  4. If 25%+ of voters say NO, the proposal is blocked.

What the maintainer can and cannot do

Can:

Deploy code · Restart the worker · Add features · Merge PRs after votes pass

Cannot:

Override a vote · Remove a resolution from history · Hide a comment (only authors can delete their own) · Change a vote tally after close

The hash chain at /api/rt/audit/verify proves the last three.
