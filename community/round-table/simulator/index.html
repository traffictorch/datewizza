What you just watched

Every scenario follows the same four phases: Propose → Discuss → Vote → Execute. The rules that govern each phase are published on the Round Table page. Two behaviors are worth noting:

  • Block beats pass. If 25% or more of voters say NO, the proposal fails — even at 66% YES. The block threshold protects minority positions from majority steamrolling.
  • Votes record intent; humans ship code. A passed code proposal doesn't auto-merge — it creates a linked PR that a human reviews. The merge SHA is recorded on the audit chain.
